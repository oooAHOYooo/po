Speculation → Core Profit Pipeline

Example

  • Cost Basis: $150
  • Current Value: $164
  • Profit = +14

How to Move Profits to the Core Account

Fidelity does not allow position transfers between two taxable individual accounts.

The correct workflow is:

  1. Sell the position in the Speculation Account
    Use: Trade → Sell
  2. Transfer the cash to the Core Account
    Use: Transfer → Transfer Between Fidelity Accounts
    Move only the profits, or the entire cash balance if desired.
  3. Rebuy long-term ETFs in the Core Account
    Examples:
    • VTI
    • FXAIX
    • SCHD
    • QQQM

This system turns speculation into a controlled profit pipeline.

Intelligent Investor Alignment

This plan is fully compliant with Graham’s philosophy:

  1. Speculation is kept small (~7% of total portfolio)
  2. Speculation is clearly labeled and isolated
  3. Core portfolio grows automatically and unemotionally
  4. Profits flow from speculation → long-term compounders
  5. Monthly contributions maintain discipline

Simple Monthly Rule

Every month:

  1. Check the speculation account.
  2. If Gain/Loss > 10%, siphon the profits to core.
  3. Leave the original speculation capital untouched.
  4. Keep auto-adding to core positions.

This creates a self-funding system for long-term wealth.
